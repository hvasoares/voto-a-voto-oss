# Voto a Voto: agent entry point

This file is a pointer only. Nothing is duplicated here.

- Read `docs/agent-brief.md` before any work: the rules, and the liveness and hand-back protocol.
- Terms (fact record, budget, base path, ready attributes, sentence catalog) are in `docs/glossary.md`, one line each with a link to the file that defines them.
- Decisions are in `docs/decisions.md` (append-only, with the reason and status of each); releases are mapped in `docs/releases.md`. A conflict between rules the log does not settle is a blocking question (see the brief).
- A ticket brief says: "Follow `docs/agent-brief.md` at commit <sha> plus the scope below".
